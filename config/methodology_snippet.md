# 龙头战法执行摘要（与 `src/methodology.py` 同步，bot 复盘/竞价按此执行）

> 改规则时请同时改 `src/methodology.py`，保证推送与 LLM Prompt 一致。

## 大前提（仓位）
- 冰点：空仓或只处理存量
- 溢价弱、炸板率高：半仓，只做龙一
- 修复/主升：方可正常接力

## 收盘后选股（四步+否决）
1. 定主线：东财涨停池按概念/原因统计 **涨停家数最多 + 成交额前排集中度**，与连板网「主线题材」**交叉确认**（不一致标待收敛）；可选 `MAINLINE_KEYWORD` 手动钉题材
2. 认龙头：首封时间 一字>秒板>早板>尾盘
3. 看位置：最高板是否还在、中间是否断层
4. 验筹码：封单占流通≥3%；一字低换手；分歧板高换手

硬条件：连板≥2、封单≥3%、炸板<3、换手≤20%、在主线板块
否决：龙二心理、高开>2%追、补涨、14:00后板、炸板≥3

## 竞价（只否决不买）
- 低开>2%删；竞价量>昨全天5%且9:20-9:25价跌→出货
- 9:30-9:40：不破开、放量、板块同步；买点9:35-9:45

## 大业体温计
- 一字/强开=线活；开板15分钟内回封=唯一分歧窗；不回封=全线撤退

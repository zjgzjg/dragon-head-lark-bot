# 龙头战法执行摘要（写入 Prompt，完整规则以你的文档为准）

## 大前提（仓位）
- 冰点：空仓或只处理存量
- 溢价弱、炸板率高：半仓，只做龙一
- 修复/主升：方可正常接力

## 收盘后选股（四步+否决）
1. 定主线：涨停家数最多 + 成交额前排集中度
2. 认龙头：首封时间 一字>秒板>早板>尾盘
3. 看位置：最高板是否还在、中间是否断层
4. 验筹码：封单占流通≥3%；一字低换手；分歧板高换手

硬条件：连板≥2、封单≥3%、炸板<3、换手≤20%、在主线板块
否决：龙二心理、高开>2%追、补涨、14:00后板、炸板≥3

## 竞价（只否决不买）
- 低开>2%删；竞价量>昨全天5%且9:20-9:25价跌→出货
- 9:30-9:40：不破开、放量、板块同步；买点9:35-9:45

## 大业体温计
- 一字/强开=线活；开板15分钟内回封=唯一分歧窗；不回封=全线撤退
